Đưa SDK NEON-MDF vào AI agent của bạn

NEON MCP là MCP server chạy trên máy bạn. Agent (Claude Code, Cursor, VS Code, Codex…) dùng nó để tra tài liệu, register và C API của GT32U2086, tạo project, build bằng CMake, kiểm tra image, nạp firmware qua UART, debug qua GDB và phân tích HardFault. Mọi dữ liệu và công cụ đều lấy từ checkout NEON-MDF của bạn.

Chạy local, không phải server online. Server cần checkout NEON-MDF, toolchain ARM và quyền truy cập cổng serial/debugger trên máy bạn, nên mỗi client tự khởi động một tiến trình neon-mcp qua stdio. Trang này chỉ hướng dẫn cài.
